What this scan does

The command nmap <target_ip> checks the target for reachable TCP services. I used it first to get a broad map of the machine before choosing what to inspect. The result shows the host is online and lists HTTP (80), Windows RPC/NetBIOS (135 and 139), HTTPS (443), SMB (445), MySQL (3306), and HTTP on 8080, plus high RPC ports. That is why I followed up with service and version detection.

What these options do

-sC runs Nmap?s standard discovery scripts, -sV probes open ports to identify service versions, and -T4 increases scan speed. I used this after the first scan to identify what was behind the ports. The output reports IIS 7.5 on port 80, Apache 2.4.23 with PHP 5.6.28 on ports 443 and 8080, Windows 7 and SMB details on 445, and MariaDB on 3306. It also shows an osCommerce 2.3.4 directory and an expired TLS certificate. These version and configuration details guided the later checks.
